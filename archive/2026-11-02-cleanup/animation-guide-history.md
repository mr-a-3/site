# Animation

Scope: hero movement, gradients, paper plane, slide/text transitions.

- `editorial/BackgroundDepth.tsx`: visibility/page/reduced-motion gates; gradient layers and paper-plane SVG.
- `editorial/background-depth.css`: gradient flow and plane flight path, mobile variants.
- `editorial/Hero.tsx`: headline reveal, slide crossfade, caption transition, autoplay/pause/swipe/keyboard.
- `editorial/motion-tokens.ts`: easing and timing.
- `editorial/ProductModel.tsx`: photograph loading and pointer tilt; no actual 3D model.
- `editorial/hero.css`: slide layout and mobile photo drift.
- `editorial/entry.tsx`: React mount.

`public/editorial/` is GENERATED by `npm run build:editorial`; edit `editorial/` sources, then rebuild and refresh.
`editorial/galaxy-field.ts` and `public/motion.js` are retained older implementations, currently unused. Do not edit them for the active gradient effect.
Gradients must fade completely before transformed layer boundaries to avoid diagonal seams.
